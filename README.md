# Круг — таймер силовой тренировки

Готовая страница для телефона. Без установки пакетов, сервера и сборки. Внутри — семь упражнений из программы на 27 октября 2026 года. По умолчанию упражнения выполняются по кругам. Все названия, веса, повторы и время отдыха можно менять.

## Как выложить через GitHub Upload files

1. Распакуй `workout-pages.zip`. Нужны **файлы внутри архива**, а не сам ZIP.
2. На GitHub создай новый репозиторий кнопкой **New repository**. Название, например, `workout`. Для бесплатного аккаунта выбери **Public**, включи **Add README**, затем **Create repository**.
3. В репозитории открой **Add file → Upload files**. Перетащи содержимое распакованного архива. `index.html` должен оказаться прямо в корне репозитория, рядом с `app.js` и `styles.css`. Не загружай всё дополнительной папкой `dist` или `workout-pages`.
4. Нажми **Commit changes**. Если GitHub предложит заменить README — используй инструкцию из архива.
5. Открой **Settings → Pages**. В **Build and deployment → Source** выбери **Deploy from a branch**. Ниже выбери ветку **main** и папку **/(root)**, нажми **Save**.
6. Дождись публикации: обычно несколько минут, иногда до 10. Адрес появится в этом же разделе: `https://ТВОЙ-ЛОГИН.github.io/workout/`.
7. Открой адрес на телефоне. Для быстрого доступа добавь страницу на главный экран через меню браузера: на iPhone — **Поделиться → На экран «Домой»**, на Android — пункт добавления на главный экран (название зависит от браузера).

Шаги публикации сверены с [инструкцией GitHub о создании Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) и [настройкой ветки и папки](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Если страница выдаёт 404, проверь расположение `index.html`, ветку `main`, папку `/(root)` и результат публикации во вкладке **Actions**. Имя файла должно быть именно `index.html`, маленькими буквами. Скрытый файл `.nojekyll` можно загрузить вместе с остальными; если проводник его не показывает, для этой простой страницы он необязателен.

## Как пользоваться

- Нажми **карандаш** у упражнения: задай число подходов, повторы отдельно для каждого, вес и отдых в секундах. Можно вводить диапазоны: `8–12`. Кнопки **Выше/Ниже** меняют порядок, **Добавить** создаёт упражнение.
- **По кругам**: первый подход каждого упражнения, затем второй круг и так далее. Упражнение с одним подходом участвует только в первом круге. Например, в исходной программе кругов три, а разведений сидя — один подход за всё занятие.
- **По упражнениям**: сначала все подходы первого упражнения, затем второго.
- Для тяги включены **отдельные таймеры правой и левой руки**. Поэтому исходные 15 подходов из таблицы дают 18 отдельных таймеров. «Мёртвый жук» выполняется с чередованием сторон внутри одного таймера.
- Нажми **Начать тренировку** непосредственно перед первым подходом. Таймер считает время выполнения вверх.
- **Закончить подход** сохраняет его время и запускает отдых. Поле фактических повторов необязательное: если его оставить пустым, в истории останется план.
- После отдыха звучит сигнал и начинается **подготовка на 10 секунд**. Можно нажать **Начать подход** сразу; иначе следующий таймер запустится автоматически. Автостарт отключается в настройках.
- Во время отдыха можно добавить **30 секунд** или закончить отдых раньше. После каждого круга отображается **сумма времени работы** всех его упражнений, включая обе руки тяги. Отдых и паузы в эту сумму не входят.
- **Пауза** замораживает любой таймер. **Завершить тренировку** сохраняет выполненное; незаконченный подход помечается отдельно. После последнего подхода — итог без лишнего отдыха.
- История хранит последние 50 тренировок с временем каждого подхода, кругов и занятия в целом.

## На телефоне

Перед занятием открой **Таймер и сигналы → Проверить сигнал** и выставь громкость. Беззвучный режим и ограничения браузера могут мешать звуку. Вибрация работает только там, где её поддерживает браузер.

Страница пытается удерживать экран включённым во время занятия; браузер может отказать, например при энергосбережении. Если свернуть страницу или заблокировать экран, время текущей работы/отдыха продолжит учитываться, но **звук в фоне не гарантируется**. Новый подход в скрытой вкладке не запускается: при возвращении после закончившегося отдыха будет новый отсчёт 10 секунд. Для обычного автоматического режима держи страницу открытой на экране. Это учитывает [ограничения фоновых вкладок](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API), [правила звука](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) и возможности [удержания экрана](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API).

Если перезагрузить страницу или закрыть браузер, сохранённая тренировка восстановится **на паузе** в момент последнего сохранения, обычно с точностью до секунды. Время после закрытия не добавляется. Для продолжения нажми соответствующую кнопку. Используй одну вкладку с тренировкой.

Программа и история сохраняются **в этом браузере на этом устройстве**, автоматически в GitHub не отправляются. Синхронизации между устройствами нет. Очистка данных сайта или приватный режим могут удалить записи. Кнопки **Скачать копию / Загрузить копию** переносят программу, настройки и историю в JSON. Незаконченная тренировка в резервную копию не входит. Храни копию у себя, загружать её в публичный репозиторий не требуется.

После первой загрузки открытая страница не требует сети для таймеров и сохранений. Для повторного открытия без интернета отдельный офлайн-режим не предусмотрен. В браузере можно также открыть локальный `index.html`; постоянное сохранение надёжнее проверять на опубликованном сайте.

## Обновление страницы

Загрузи новые версии файлов тем же **Upload files** в корень и подтверди изменения. После окончания публикации обнови страницу на телефоне, когда тренировка не идёт. При сохранении адреса и браузера программа и история останутся. Менять код ради добавления упражнений не нужно.

## Состав файлов

`index.html` — страница, `styles.css` — оформление, `engine.js` — таймеры, `app.js` — интерфейс и сохранение, `icon.svg` — значок, `.nojekyll` — отключение обработки Jekyll, `README.md` — эта инструкция. Все ссылки относительные, поэтому страница работает и в репозитории с любым названием.
